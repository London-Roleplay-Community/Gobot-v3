# Security Policy

## Supported Versions

All versions of the updated v3 Gobot are being maintained.

| Version | Supported          |
| ------- | ------------------ |
| v3.x.x  | :white_check_mark: |
| v2.x.x  | :x:                |
| v1.x.x  | :x: |

## Reporting a Vulnerability

If you find a security vulnerability, please send me an email at [jaxon@jxson.tech](mailto:jaxon@jxson.tech) or report through the [Security and Quality](https://github.com/London-Roleplay-Community/Gobot-v3/security) tab.

If it's a major vulnerability, the vulnerability will be fixed within 1-3 days. If it's a minor vulnerability, it may take up to 2 weeks to publish a fix. **Please do not report vulnerabilities through Github issues.**

### Make sure to include these details in your report:
* Type of issue
* Path of the source files related to the issue
* The line number(s) & file name
* Instructions to reporuce the issue
* Proof of the exploit or vulnerability _(optional)_
* Impact of the vulnerability (low, medium, high, very high)
